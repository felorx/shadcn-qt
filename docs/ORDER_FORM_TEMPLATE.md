# Commercial Order Form template

Complete every bracketed field. This template is an operational starting point
and should be reviewed by counsel for the seller and target markets.

## Parties and order

| Field | Value |
| --- | --- |
| Order ID | `[unique-id]` |
| Effective date | `[YYYY-MM-DD]` |

| Field | Value |
