# Community vs Pro

See the canonical document in the repository: [docs/TIERS.md](https://github.com/qtshadcn/qtshadcn/blob/main/docs/TIERS.md).

**Summary**

- **Community (MIT)**: core shadcn-aligned primitives, token codegen, Python + C++, docs site source.
- **Pro (commercial, planned)**: advanced DataTable/navigation/charts, Designer plugins, multi-brand tooling, private registry — shipped as a separate artifact; `qtshadcn.pro` is not included in OSS builds.
